# YT Vault — запуск сайта

Адаптивное тёмное веб-приложение для поиска видео через YouTube Data API v3. Загрузка предусмотрена только по прямым ссылкам на файлы, которые предоставлены автором/правообладателем и разрешены к скачиванию.

## Требования
- Node.js 18 или новее
- YouTube Data API v3 key из Google Cloud Console

## Запуск локально
1. Распакуй архив.
2. Скопируй `.env.example` в `.env`.
3. В `.env` укажи `YOUTUBE_API_KEY=твой_ключ`.
4. Запусти `npm start`.
5. Открой `http://localhost:3000`.

## Получение API key
1. Открой Google Cloud Console: https://console.cloud.google.com/
2. Создай проект или выбери существующий.
3. Включи YouTube Data API v3.
4. Создай API key.
5. Ограничь ключ API-ограничением только для YouTube Data API v3 и настрой квоты.

## Что работает
- Поиск YouTube через серверный endpoint (ключ не отправляется в браузер).
- Карточки с превью, названием и каналом.
- Окно подробностей и переход на оригинальное видео.
- Поле прямой ссылки на файл, предоставленной правообладателем.
- История последних разрешённых загрузок и очистка истории.
- Адаптивный интерфейс для телефона и компьютера.

## Важное ограничение
YouTube Data API возвращает метаданные и результаты поиска, но не сами видеофайлы и не разрешение на скачивание. Этот проект намеренно не извлекает YouTube stream URLs и не обходит DRM, ограничения доступа или условия платформы. Для сохранения в галерею используй файл/ссылку, которую автор или правообладатель явно разрешил скачивать. На мобильном устройстве поведение сохранения зависит от браузера; iPhone может потребовать сохранить файл через «Файлы» → «Поделиться» → «Сохранить видео».


## Вставка прямой ссылки на файл
На главной странице есть отдельное поле для прямой ссылки на видеофайл (например, MP4). Оно работает независимо от YouTube API key. Поддерживается открытие прямых HTTP(S)-ссылок с расширениями MP4, MOV, M4V и WebM. Обычная ссылка YouTube не является прямой ссылкой на видеофайл и не будет загружена. Пользователь должен иметь право на скачивание файла. На iPhone Safari может открыть видео; затем используйте «Поделиться» → «Сохранить видео», если формат и источник это поддерживают.


## Обычные ссылки YouTube
Добавлено поле для распознавания ссылок youtube.com/watch, youtu.be, Shorts, embed и live. Оно проверяет формат ссылки и предлагает открыть ролик на YouTube. Оно не скачивает видео YouTube в MP4: для этого нужна разрешённая прямая ссылка на файл либо официальная функция YouTube.
